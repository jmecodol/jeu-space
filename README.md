# jeu-space

Le site affiche uniquement une page blanche. Le jeu et ses ressources ont été retirés.

Ouvrez `index.html` pour consulter la page localement.

La publication GitHub Pages depuis une branche utilise `index.html` à la racine.
Le workflow `.github/workflows/deploy.yml` publie également ce fichier après un push sur `main` ou un lancement manuel.
